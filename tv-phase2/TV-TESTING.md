# Prototype test handoff

Build first, then install and launch only `com.sonytvvibe.launcher` on an explicitly authorized TV. Do not select a new default Home app during the first test.

Test D-pad focus on every Home favourite, Search, Settings, Browse Apps, the Media submenu, first/last app-grid cells, paging, Back behavior, and return-from-app focus. Verify unreadable icon/banner artwork and long names on the actual TV panel; browser mockups do not prove native rendering.

Test voice, casting, Bluetooth audio, USB playback, and the stock-launcher return path on the target firmware. Package presence and component resolution do not prove a service works after launch.

Only after these checks should the owner choose the launcher under the TV's Home/default-app setting. Keep the stock launcher installed and selectable as a fallback.
