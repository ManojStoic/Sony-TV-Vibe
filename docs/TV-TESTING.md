# TV testing and launcher switching

Install and launch the prototype explicitly before changing the default Home app. Confirm the display size, overscan, D-pad focus, Search, app return, Media submenu, voice, casting, Bluetooth audio, and stock launcher fallback on the physical television.

When the owner is satisfied, use the television's own Settings path for default Home apps and select **TV Vibe Preview**. The exact menu names vary by firmware. To return to the original experience, use the same setting and select the stock launcher.

Do not disable or uninstall the stock launcher. Keeping it installed and selectable is the recovery path if a custom launcher fails to start or an update has a defect.
